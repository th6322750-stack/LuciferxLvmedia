# LuciferxLvmedia

Central AI Context / Knowledge Base for Lucifer.

Repository này là bộ não trung tâm dùng để lưu hồ sơ làm việc, quy tắc phối hợp với AI, bối cảnh nghề nghiệp, dự án, quyết định và bài học tích lũy theo thời gian.

> Entry point cho AI: `AI_CONTEXT.md` (được phát triển trên branch/PR riêng trước khi merge).

## Nguyên tắc

- Không lưu password, API key, private key, token hoặc secret.
- Không tự merge Pull Request nếu chưa có quyết định của Lucifer.
- Thông tin có khả năng thay đổi theo thời gian phải được kiểm tra nguồn hiện tại trước khi kết luận.
- Repo là living knowledge base: liên tục học hỏi, cập nhật và ghi lại quyết định/bài học qua từng job.
